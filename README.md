## 🚀 About Me

I am a software development student specializing in full-stack web systems, cross-platform mobile development, and practical AI tool integration. My work focuses on bridging clean, scalable system architecture with intuitive user interfaces—from designing high-fidelity prototypes to engineering local-first applications.

- 🎓 **Education:** Pursuing a Diploma in Mobile and Web Development Using AI at triOS College.
- 🛠️ **Current Focus:** Full-stack web architectures, UI/UX prototyping, local-first LLM applications (MCP protocol), and relational database design.
- 💻 **Hands-On Experience:** Building responsive web apps, RESTful API integrations, and modular desktop/mobile layouts.
- 🎨 **Design & Workflow:** Applying atomic design principles, structured wireframing, and git-based team workflows.
